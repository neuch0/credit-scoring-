# pshnt2026_ML

Исходный датасет это train.csv из https://www.kaggle.com/datasets/maksimkotenkov/credit-scoring-dataset/
В коде предполагается, что train.csv находится в папке Data

Запускать файлы по порядку.

Описание по файлам:
1)Обработка данных и прогон на логреге
2)Новые признаки + отбор лучших + логрег,кнн,рф
3)Отбор лучших признаков + катбуст
4)Сравнение моделей
5)Графики со всех файлов (todo: определиться как структурировать графики. в файлах с кодом они мозолят глаза и мешаются, а если отдельно их выводить, то нужно иметь кучу мусорных файлов)
